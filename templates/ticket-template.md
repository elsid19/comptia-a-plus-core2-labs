# IT Support Ticket Write-Up Template

Use this template to document every ticket you work — whether in a lab, a home lab,
or a real environment. Thorough documentation builds three habits that matter in IT:
it forces you to articulate *why* a fix worked (not just that it did), it creates a
searchable knowledge base for future incidents, and it demonstrates professional
competence to employers and auditors.

This format is compatible with most enterprise ticketing systems including
ServiceNow, Jira Service Management, and Zendesk — paste each section into the
corresponding fields, or use the whole file as a work log.
