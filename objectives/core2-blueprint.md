# CompTIA A+ Core 2 (220-1202) Exam Blueprint

> Total exam questions: 90 | Time: 90 minutes | Passing score: 700/900

---

## Domain 1 — Operating Systems (28%)

- 1.1 Identify basic features of Microsoft Windows editions
  - Windows 10/11 Home, Pro, Pro for Workstations, Enterprise
  - Feature differences: BitLocker, Group Policy, Remote Desktop, Hyper-V
- 1.2 Use the appropriate Microsoft command-line tool
  - `cd`, `dir`, `md`, `rd`, `copy`, `xcopy`, `robocopy`, `del`, `format`, `diskpart`
  - `ipconfig`, `ping`, `tracert`, `nslookup`, `netstat`, `net user`, `net use`
  - `sfc /scannow`, `chkdsk`, `shutdown`, `gpupdate`, `gpresult`
- 1.3 Use features and tools of the Microsoft Windows OS
  - Task Manager, Device Manager, Event Viewer, Registry Editor
  - MMC snap-ins: lusrmgr, services.msc, compmgmt.msc, diskmgmt.msc
  - System Configuration (msconfig), System Information (msinfo32)
- 1.4 Use the appropriate Windows settings
  - Settings app vs. Control Panel
  - Display, personalization, network, update, privacy settings
- 1.5 Given a scenario, use the appropriate Windows administrative tool
  - Local Users and Groups, Group Policy Editor (gpedit.msc)
  - Disk Management, Task Scheduler, Performance Monitor
- 1.6 Explain the differences in Windows OS upgrade methods
  - In-place upgrade, clean install, image deployment, repair installation
- 1.7 Given a scenario, perform OS installations and upgrades
  - Boot methods: USB, optical, PXE, partition requirements
- 1.8 Identify the features and tools of macOS
  - Finder, Spotlight, iCloud, FileVault, Time Machine, Keychain
- 1.9 Identify the features and tools of Linux
  - Common distros, shell/terminal basics, file permissions, package managers

## Domain 2 — Security (28%)

- 2.1 Summarize various security measures and their purposes
  - Physical security: locks, badges, cameras, fencing, guards
  - Logical security: ACLs, principle of least privilege, MFA
- 2.2 Compare and contrast wireless security protocols and authentication methods
  - WEP, WPA, WPA2, WPA3; TKIP vs. AES; RADIUS; enterprise vs. personal
- 2.3 Given a scenario, detect, remove, and prevent malware
  - Virus, worm, Trojan, ransomware, spyware, adware, rootkit, keylogger
  - Anti-malware tools, quarantine, recovery steps
- 2.4 Explain common social engineering attacks, threats, and vulnerabilities
  - Phishing, vishing, smishing, shoulder surfing, tailgating, dumpster diving
  - Zero-day, on-path (MITM), brute force, dictionary attacks
- 2.5 Given a scenario, manage and configure basic security settings in the Windows OS
  - UAC, Windows Defender, Windows Firewall, BitLocker, EFS
  - User account types, password policies, screensaver locks
- 2.6 Given a scenario, configure a workstation to meet best practices for security
  - Account management: rename admin, disable guest, strong passwords
  - AutoRun/AutoPlay disabled, patching schedule, host-based firewall
- 2.7 Explain common methods for securing mobile and embedded devices
  - Screen locks, remote wipe, MDM, full device encryption
- 2.8 Given a scenario, use common data destruction and disposal methods
  - Overwriting, degaussing, shredding, incinerating; certificate of destruction
- 2.9 Given a scenario, configure appropriate security settings on SOHO wireless networks
  - SSID management, MAC filtering, port forwarding, DMZ, content filtering
- 2.10 Given a scenario, install and configure browsers and relevant security settings
  - Pop-up blockers, certificate warnings, private browsing, extensions

## Domain 3 — Software Troubleshooting (23%)

- 3.1 Given a scenario, troubleshoot common Windows OS problems
  - Slow performance, boot issues, application crashes, BSOD
  - Missing DLL, service won't start, profile errors
- 3.2 Given a scenario, troubleshoot common personal computer (PC) security issues
  - Unexpected pop-ups, browser redirect, renamed system files
  - Unwanted programs, high CPU/network from unknown processes
- 3.3 Given a scenario, use best practice procedures for malware removal
  - 1. Identify symptoms → 2. Quarantine → 3. Disable System Restore
  - 4. Remediate → 5. Schedule scan → 6. Re-enable System Restore → 7. Educate user
- 3.4 Given a scenario, troubleshoot common mobile OS and application issues
  - App crashes, slow response, connectivity issues, battery drain
- 3.5 Given a scenario, troubleshoot common mobile OS and application security issues
  - Unexpected data usage, leaked credentials, fake security warnings

## Domain 4 — Operational Procedures (21%)

- 4.1 Compare and contrast best practices associated with types of documentation
  - Network diagrams, knowledge base, incident documentation, change management
- 4.2 Given a scenario, implement basic change management best practices
  - Change request, approval, rollback plan, impact analysis, testing
- 4.3 Given a scenario, implement workstation backup and recovery methods
  - Full, incremental, differential; 3-2-1 backup rule; cloud vs. local
  - System Restore, Windows Backup, File History
- 4.4 Given a scenario, use common safety procedures
  - ESD precautions, proper lifting, cable management, fire suppression
- 4.5 Summarize environmental impacts and local environmental controls
  - MSDS/SDS sheets, proper battery/toner disposal, temperature/humidity
- 4.6 Explain the importance of prohibited content/activity and privacy, licensing, and policy concepts
  - PII, GDPR, HIPAA, incident response, licensing (OEM, retail, open source)
- 4.7 Given a scenario, use proper communication techniques and professionalism
  - Active listening, avoid jargon, set expectations, follow up
- 4.8 Identify the basics of scripting
  - PowerShell, Python, batch files; use cases for automation
- 4.9 Given a scenario, use remote access technologies
  - RDP, VPN, VNC, SSH, screen-sharing tools, security considerations
